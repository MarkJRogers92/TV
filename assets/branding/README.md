# MarkTV branding

`marktv-logo-canonical.png` is the approved canonical MarkTV logo (2026-09-18).

Preserve the antenna geometry exactly: the **T** leans left; the **V** has two full, equal arms; both letters sit on the same rounded antenna base. The CRT body and the brush-lettered **MARK** screen treatment are part of the canonical mark.

`web/public/marktv-logo.png` is the web-ready copy of the same asset.

The existing `web/public/marktv-watermark.png` is a separate broadcast-overlay asset and should not be replaced automatically by the full logo.
